# 本地模式说明与卸载/回滚指南

## 当前配置

系统默认运行在**本地模式**：生成端为 Ollama + Qwen2.5-7B（Q4 量化），
断网可用、零成本。检索端（向量/BM25/重排）始终是本地 GPU，与生成端无关。

- 程序位置：`S:\Ollama`（含卸载器 `unins000.exe`）
- 模型位置：`S:\Ollama\models`（由用户环境变量 `OLLAMA_MODELS` 指定，C 盘零占用）
- 开机自启：**无**（无服务、无注册表项、无计划任务，均已核实）；
  本地 LLM 由 `启动知识库问答.bat` 按需拉起、`停止知识库问答.bat` 一键停止
- C 盘足迹：仅 `C:\Users\<用户>\.ollama`（约 10KB 客户端密钥，程序自动生成）
- 显存：7B 模型 + 检索模型共约 5.8GB / 8GB；停止脚本运行后全部释放

## 切换生成端（本地 ↔ 云端）

编辑项目根目录 `.env`：本地模式和云端模式两段配置二选一（注释/取消注释），
保存后重启程序。云端为阿里云百炼 qwen3.7-max，质量更高（实验报告第四章：
6 题横评云端 6/6、本地 3/6），每题成本约 0.003 元。

## 完全卸载 Ollama（无残留）

1. 双击 `停止知识库问答.bat`（或在任务管理器结束 ollama.exe）
2. 运行 `S:\Ollama\unins000.exe` 卸载程序
3. 删除 `S:\Ollama` 文件夹（回收 6GB+，含模型）
4. 删除 `C:\Users\<用户>\.ollama` 文件夹（10KB 密钥）
5. （可选）清除环境变量：`setx OLLAMA_MODELS ""`
6. 把 `.env` 切回云端模式（否则本地模式会连不上 127.0.0.1:11434——
   注意：连不上时系统会报错而不是静默降级，这是有意设计）

## 常见问题

- **启动 bat 后问答报"Connection error"**：本地 LLM 没起来，看任务栏是否有
  ollama-serve 窗口；手动开一个终端跑 `set OLLAMA_MODELS=S:\Ollama\models`
  然后 `S:\Ollama\ollama.exe serve` 排查
- **首次提问慢**：模型懒加载约 15-25 秒，之后本地生成约 2-5 秒/题
- **打游戏前**：双击停止脚本释放显存
